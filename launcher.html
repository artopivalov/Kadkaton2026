Ebaboba / рабочая площадка

Куда отправимся?

Все режимы проекта в одном месте. Открываются в новых вкладках.

Откройте файл StartKadkaton.command двойным кликом в Finder. Он сам запустит всё и откроет эту страницу.
01 / DEBUG

Дебаг

Площадка для проверки палочек, рун, врагов и боевых механик.

Открыть дебаг ↗
02 / GAME

Игра

Основной билд: лобби, порталы и прохождение локаций.

Открыть игру ↗
03 / SCENES

Сцены

Просмотр Forest, Cave и Library. Свободная камера, выбор seed и пересоздание карты.

Открыть сцены ↗
04 / SERVER

Сервер

Запуск и остановка сетевой игры, публичный адрес, комнаты и логи. Для мультиплеера откройте игру по адресу из панели.

Открыть панель ↗

Запуск без терминала: StartKadkaton.command. Команда вручную: npm run launch

Держите вкладку панели сервера открытой во время сетевой игры: её закрытие останавливает сервер.
