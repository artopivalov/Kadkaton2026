# Kadkaton: прототип лобби

Запуск из папки проекта: `python3 -m http.server 8000`, затем открыть http://localhost:8000. Для телефона открыть `http://<IP компьютера>:8000` в той же локальной сети. Node.js нужен только для тестов: `npm test` или `node --test`. Зависимостей и сборки нет.

Весь интерфейс, подсказки, технические сообщения и код — на английском. Введённое игроком имя сохраняется как есть. Имя и цвет хранятся в localStorage. В меню есть превью персонажа, которое сразу меняет цвет при выборе; оно использует ту же функцию отрисовки, что и игровой персонаж. Русский используется только в документации и общении.

Работают меню Start game / Host game / Join game (последние две — заглушки), лобби, один джойстик для мыши/сенсорного ввода, WASD/стрелки, три режима, выбрасывание палочки нажатием на слот и автоподбор в свободный слот. Слот руны пока пустой.

Игра использует портретный кадр на всех экранах: на компьютере 9:16 с полями по бокам, на вертикальном телефоне — вся доступная высота и ширина. Камера следует за игроком по горизонтали; на более узком экране боковой обзор меньше. Камера отдалена до 72% исходного масштаба (примерно на 39% больше пространства по каждой оси); параметр `cameraZoom` хранится в файле баланса.

Управление расположено по UX-правкам GDD: вертикальный ползунок слева внизу, джойстик по центру внизу, две иконки слотов справа (палочка сверху, руна снизу). Положения ползунка снизу вверх: Safe, Normal, Special. Переключение свайпом, нажатием на положение или стрелками при фокусе на ползунке; Home/End выбирают крайние положения.

## Режимы и временные решения

Из обновлённого GDD: Safe не стреляет, Normal использует обычное заклинание, Special у Fireball создаёт огненную сферу вокруг персонажа и заряжается значительно дольше.

- Safe: движение без стрельбы.
- Normal: движение и зарядка при удержании направления; отпускание джойстика или последней клавиши движения выпускает фаерболл. Частичный заряд разрешён.
- Special: удержание направления заряжает сферу; при полном заряде отпускание создаёт огненную волну вокруг текущей позиции персонажа и наносит урон всем мишеням в радиусе. Раннее отпускание отменяет заряд.
- Смена режима, выбрасывание, отмена жеста и потеря фокуса сбрасывают заряд без выстрела.

Жест выпуска, требование полного заряда Special и численные значения — временные решения прототипа. Все параметры механик хранятся в `src/balance.js`: обычный заряд 1,2 с, Special 3,6 с, радиус сферы 180, урон сферы 30, обычного выстрела 10. Соотношение времени 3:1 — временная настройка, а не утверждённый баланс.

Урон отображается на тренировочных мишенях накопительным счётчиком; мишени не уничтожаются. Урон самому заклинателю, мана, здоровье и friendly fire ещё требуют определения. Сфера наносит урон один раз при выпуске, её анимация длится 0,7 с. Сетевая игра, порталы, биомы, враги и боссы не входят в этап.

## Структура и проверка

`src/balance.js` — единый файл параметров механик. `src/simulation.js` — сериализуемое состояние и правила. `src/main.js` — ввод, экраны и UI. `src/renderer.js` — заменяемая примитивная графика. `style.css` — портретная компоновка.

Восемь тестов симуляции проверяют движение, режимы, заряд, огонь, диапазон, попадания, выбрасывание и автоподбор, а также Special и урон по всем мишеням в области. Проверка на реальном сенсорном телефоне остаётся необходимой.

UX-проверка: превью и мгновенная смена цвета, переключение ползунка свайпом и клавишами проверены в браузере. На 320×740 элементы управления не перекрываются; также проверена широкая компоновка с портретным игровым полем.
