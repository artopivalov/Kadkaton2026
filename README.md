# Kadkaton: прототип с тремя билдами

## Запуск и сборка

Из папки проекта: `python3 -m http.server 8000`.

- Исходники (по умолчанию отладочная площадка): http://localhost:8000/
- Отладочный билд: http://localhost:8000/dist/debug/
- Отладка генерации: http://localhost:8000/dist/generation/
- Основной билд: http://localhost:8000/dist/game/

Собрать все три: `npm run build` или `node scripts/build.mjs`. Только один: `npm run build:debug` / `npm run build:game` / `npm run build:generation`. Тесты: `npm test` или `node --test`. Для сборки и тестов нужен Node.js; внешних зависимостей и шага установки нет.

Для телефона открыть тот же путь через `http://<IP компьютера>:8000` в одной локальной сети. Для передачи основного билда достаточно папки `dist/game`; она работает как самостоятельный статический сайт. Отладочная сцена и её тестовые данные туда не копируются. Сборка заменяет только помеченные ею выходные папки; отказывается перезаписывать чужую папку без маркера. `dist/` исключена из Git.

## Сцены

Меню одинаковое для трёх билдов: превью с мгновенным перекрашиванием, имя и цвет с сохранением в localStorage, Play, заглушки Host game / Join game.

**Отладочная площадка:** 17 подписанных постаментов: Fireball, Ice, Lightning, Air, Earth, Nature, Gravity, Light, Crystal, Blood, Storm, Void, Mirror, Orbit, Comet, Prism, Test Wand. Подойдите к постаменту — палочка автоматически заменится даже в занятом слоте. Постамент остаётся на месте. Повторная замена происходит при новом подходе; простое стояние рядом не сбрасывает заряд. Три подвижные тренировочные мишени и постоянная стенка позволяют проверять урон, отталкивание и рикошеты. Стартовая палочка — Test Wand.

**Основной билд:** лобби с безопасной Test Wand и тремя доступными порталами: Forest, Cave, Library. Переход происходит, когда все игроки стоят в одном портале. Локации содержат соответственно 10/15/20 круглых POI, соединённых коридорами; лес линейный, пещера с короткими ответвлениями, библиотека с цепочками тупиков до трёх POI. Камера следует за игроком по обеим осям. В каждой локации доступны ближние и дальние враги своего биома, финальный босс и общий лут. Победа требует уничтожить всех врагов последней комнаты, включая босса; затем доступен возврат в лобби. После смерти можно вернуться в лобби и начать заново.

В обеих сценах можно выбросить палочку нажатием на слот и подобрать её в пустой слот. Обычный предмет на земле не заменяет занятую палочку. После выбрасывания действует задержка повторного подбора 0,8 с. Правило автоматической замены на постаменте существует только там, где сцена содержит постаменты.

**Отладка генерации:** отдельная сборка `generation`, свободная камера без коллизий (джойстик / WASD / стрелки). Выберите Forest, Cave или Library и seed, затем нажмите Regenerate. Повтор того же seed воспроизводит карту. Используются те же генератор и полный спавн врагов/предметов, что в основной игре. Камера не ограничивает спавн. Персонаж не отображается, симуляция боёв заморожена для осмотра. Обе отладочные сцены исключены из основной сборки.

## Палочки

| Палочка | Normal | Special |
|---|---|---|
| Fireball | Огненный снаряд со взрывом при попадании | Сфера огня вокруг персонажа |
| Ice | Веер маленьких сосулек | Летящая вперёд волна холода, поражает каждую мишень один раз |
| Lightning | Мгновенная линия молнии | Удар с неба в точку впереди; прицел удаляется при зарядке; применяется при отпускании даже с частичным зарядом и игнорирует стену на пути |
| Air | Вихрь наносит урон при попадании и расталкивает близкие цели | Сфера наносит урон и сильно отталкивает цели от персонажа |
| Earth | Катящийся камень рикошетит от стен и границ | Временная твёрдая стена перед персонажем, не имеет здоровья и не разрушается атаками |
| Nature | Колючка с корнями | Замедляющие лозы |
| Gravity | Снаряд с притяжением | Притягивающий колодец с периодическим уроном |
| Light | Возвращающийся диск | Проходимая стена, блокирующая снаряды |
| Crystal | Наводящийся осколок, разделяется на два | Ловушка со взрывом и осколками |
| Blood | Лечит владельца при попадании во врага | Веер игл за здоровье и ману |
| Storm | Цепная молния с ослаблением | Облако с повторными ударами |
| Void | Медленный пробивающий снаряд | Притяжение и взрыв разлома |
| Mirror | Перехватывает вражеский снаряд | Зеркало с ограниченным отражением |
| Orbit | До трёх временных спутников | Запускает спутники веером |
| Comet | Разгоняется, урон растёт с дистанцией | Метеор с предупреждением и обломками |
| Prism | Пробивающий луч | Призма превращает следующие Normal в три луча |
| Test Wand | Искры без урона, слегка отталкивающие цель | Безопасная сфера без урона и отталкивания |

Special всех палочек, кроме Lightning, в текущем прототипе требует полного заряда. При попытке создать стену Earth на персонаже, мишени или другой стене стена не создаётся. Для простой геометрии стена ориентируется по одной из двух осей, поперёк основного направления прицеливания. Камень наносит урон каждой цели не более одного раза за применение.

## Управление и баланс

Игра портретная: на широком экране 9:16, на вертикальном телефоне — вся доступная высота и ширина. В локациях камера следует за персонажем. Справа — непрерывный вертикальный слайдер зума: снизу отдаление (.35), сверху приближение (1.25), начальное значение .72; масштаб меняется плавно. Слева внизу — вертикальный ползунок Safe/Normal/Special снизу вверх, на игровом поле — плавающий джойстик под пальцем, справа — слот палочки и слот руны. Ползунок переключается свайпом, нажатием или стрелками при фокусе; Home/End выбирают края.

Зарядка идёт от удержания джойстика или игрового поля, даже в центре джойстика, без движения. WASD/стрелки — движение и удержание для зарядки; противоположные клавиши останавливают движение, сохраняя зарядку. Все атаки срабатывают при отпускании. Safe не стреляет. Смена режима, выбрасывание, смена палочки на постаменте, отмена жеста и потеря фокуса отменяют заряд.

Временные числа собраны в `src/balance.js`. Минимум дальности Normal — 1% максимума, минимум урона — 0,01%; рост идёт по квадрату заряда. Fireball растёт от радиуса 0,6 до 12. Серия из 20 нажатий по 40 мс наносит менее 5% урона одного полного Fireball. Значения и кривая ещё требуют балансировки. Стена Earth существует 6 секунд — временное число из файла баланса.

Временное правило коллизий: стены блокируют персонажа, отталкиваемые цели, обычные снаряды, линию Lightning и волну Ice. Камень Earth рикошетит, удар Lightning с неба применяется напрямую за стеной. GDD ещё не определяет все взаимодействия атак со стенами; эти правила нужно проверить отдельно. Здоровье, мана, руны, враги, локации и боссы реализованы с временными числами. Самоурон исключён, friendly fire составляет 50%. Реальный сетевой транспорт ещё не реализован: Host / Join остаются заглушками, сетевой план находится в разделе 16 GDD.

## Структура и проверка

- `scripts/build.mjs`: изолированные статические сборки.
- `src/scene.js`: точка входа сцены, заменяемая сборкой.
- `src/scenes/debug.js` / `lobby.js`: отдельные сцены и их данные; `createScene(profile?, {seed})`.
- `src/balance.js` / `wands.js`: параметры и определения всех палочек, правило friendly fire (`PVP_BALANCE`).
- `src/simulation.js`: общее состояние, заклинания, коллизии, предметы, постаменты и порталы.
- `src/rng.js`: детерминированный генератор по seed.
- `src/main.js` / `renderer.js` / `style.css`: ввод, заменяемая графика и адаптивный UI.

## Подготовка к мультиплееру

Сети пока нет, но симуляция уже рассчитана на нескольких игроков (подробности и принятые решения: раздел 16 GDD).

- Состояние мира — обычные JSON-данные: `state.players` (у каждого игрока `id`), предметы, снаряды, эффекты, стены, `seed`.
- Правила принимают id игрока: `release(state, id)`, `setMode(state, id, mode)`, `dropWand(state, id)`. Новые игроки добавляются через `addPlayer(state, profile)`, уходят через `removePlayer`.
- Один тик: `step(state, inputs, dt)`, где `inputs[id] = {x, y, held, commands}`. Команды `setMode`, `drop`, `release`, `cancel` выполняются в начале тика, поэтому отпускание между кадрами не теряется. `main.js` собирает ввод локального игрока и вызывает `step` с фиксированным шагом 1/60 с.
- Friendly fire наносит 50% урона (`PVP_BALANCE.friendlyFireMultiplier`); атака не поражает своего владельца. Здоровье уменьшается от фактического урона; `hits` и `damage` сохраняются для отладки.
- Портал открывается группе, только когда в нём стоят все игроки: `readyPortal(state)`. Локальный цикл выполняет переход всей группы в выбранную локацию.
- Карту должен строить каждый клиент по общему seed: `createRandom(seed)` для чистых генераторов, `nextRandom(state)` внутри симуляции. Генератор карты реализован в `src/generator.js`.
- Не сделано: транспорт, хост и снимки состояния, кнопки Host/Join, столкновения игроков.

## Временные правила нового прототипа

- POI независимо выбираются с вероятностями 50% бой / 50% загадка. Прототип загадки: наступить на три пронумерованные плиты по порядку; решается одним или несколькими игроками.
- После завершения POI подойдите к сундуку. Он открывается один раз и создаёт ровно два общих предмета; каждый независимо имеет шанс 50% быть боевой палочкой или руной. Подбор идёт в порядке игроков в симуляции. Занятый слот не заменяется. В начале локации каждый игрок сразу получает случайную боевую палочку; входная площадка безопасна.
- Руны: от одного до пяти случайных модификаторов по редкости Common–Legendary; доступны Damage, Range, Size, Projectile Speed, Charge Time, Spread, Mana Cost. Величины непрерывные от −20% до +50/60/70/80/90% по редкости по полезности, штрафы выпадают с шансом 20%; повторы перемножаются. Модификаторы пересчитывают Normal и Special. Слот руны позволяет выбрасывать предмет.
- Враги: skeleton / archer, goblin / goblinArcher, orc / orcArcher. Ближние преследуют и атакуют рядом; дальние выпускают прямые снаряды, стены блокируют их. В коридорах 1–2 врага, в боевых POI 3–6; характеристики растут с прогрессом и размером группы. Спавн полный и детерминированный, агро 450; после атаки враг и ближайшая группа сохраняют атакующего целью.
- Боссы имеют временные паттерны: радиальные пули, конус, удар по зафиксированной области. Красное предупреждение появляется за 1.8 с; атака соответствует его положению и форме. Cave/Library boss — временные названия и способности.
- Игрок: 100 здоровья, 100 маны, восстановление 3 маны/с, базовый Normal стоит 6 маны, Special 32 до модификаторов. При смерти игрок перестаёт двигаться/стрелять; Return to lobby сбрасывает текущий проход. Эти значения, коэффициенты врагов, загадка и правила результата — решения прототипа, а не утверждённый финальный дизайн.
- Карта и состояние сериализуются в JSON, генерация зависит от seed. Сохраняются отдельные игроки, групповой портал, shared loot и friendly fire как основа будущего кооператива; WebRTC, комнаты, сервер и предсказание клиентов остаются следующим этапом.

Новые модули: `src/generator.js` — граф и геометрия карты; `src/locations.js` — вход в локацию, спавн, ИИ, POI и сундуки; `src/scenes/generation.js` — свободная камера. Проверки генерации и прохождения: `tests/locations.test.js`.

## Обновление после игрового теста

Внесены все 11 правок GDD. Арены и коридоры просторнее, радиус агро после повторного теста установлен в 450, развилки имеют два выхода ±45°. Победа наступает после уничтожения всех врагов последней комнаты, включая босса. Fireball получает splash-взрыв, Ice Special гарантированно удаляется после завершения. UI включает плавающий джойстик, читаемый индикатор здоровья и полосы над волшебниками; слоты устойчиво принимают нажатия для выбрасывания.

Добавлены Nature, Gravity, Light и Crystal, общая модель семи базовых статов и редкости предметов с цветными обводками. Отладочная площадка расширена: все 17 палочек на постаментах, переключатель Item rarity и станция случайных рун. Для новой руны подойдите к станции; она заменяет текущую. Выйдите из радиуса и вернитесь для повторной выдачи. Бонусы руны показаны под статусом заклинания.

`src/items.js` отвечает за генерацию предметов и модификаторы; `src/wands.js` — базовые характеристики и производные параметры. Числа и временные правила находятся в `src/balance.js`, подробности — в приложении GDD. Дополнительно проверены новые заклинания, JSON-детерминизм, редкости, дробная дальность Ice и условие победы. Реальный телефон пока не проверен.


## Новое расширение и повторный тест

Добавлены Blood, Storm, Void, Mirror, Orbit, Comet, Prism и все 11 особых эффектов рун. Crystal начинается с Uncommon; Blood/Mirror — Rare, Storm/Orbit — Epic, Void/Comet/Prism — Legendary. Каждый источник соблюдает минимальную редкость. Палочки получают сохраняемые случайные статы −20%…+30%; Rare+ руны имеют шанс 30% получить один особый эффект.

Новые враги: Прыгун, Крючник, Чародей; редкие биомные — Грибной пастух, Кристальный панцирь, Переписчик. Пастух призывает убиваемые грибы. ИИ и паттерны находятся в `src/enemies.js`, расширенные заклинания — в `src/spells.js`.

Внесены все десять правок повторного теста: групповое постоянное агро, заметный расход маны, увеличенные арены/коридоры, урон контролирующих атак, ослабление пробивания, новые диапазоны рун и случайные статы, прозрачные предупреждения. Числа находятся в `src/balance.js`.

На площадке доступны выбор особого эффекта руны, спавн любого врага и очистка. После смерти нажмите Reset playground. Новые комнаты-загадки и 5–7 плит пока остаются в документации.
