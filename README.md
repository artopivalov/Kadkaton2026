# Kadkaton: прототип с двумя билдами

## Запуск и сборка

Из папки проекта: `python3 -m http.server 8000`.

- Исходники (по умолчанию отладочная площадка): http://localhost:8000/
- Отладочный билд: http://localhost:8000/dist/debug/
- Основной билд: http://localhost:8000/dist/game/

Собрать оба: `npm run build` или `node scripts/build.mjs`. Только один: `npm run build:debug` / `npm run build:game`. Тесты: `npm test` или `node --test`. Для сборки и тестов нужен Node.js; внешних зависимостей и шага установки нет.

Для телефона открыть тот же путь через `http://<IP компьютера>:8000` в одной локальной сети. Для передачи основного билда достаточно папки `dist/game`; она работает как самостоятельный статический сайт. Отладочная сцена и её тестовые данные туда не копируются. Сборка заменяет только помеченные ею выходные папки; отказывается перезаписывать чужую папку без маркера. `dist/` исключена из Git.

## Сцены

Меню одинаковое для двух билдов: превью с мгновенным перекрашиванием, имя и цвет с сохранением в localStorage, Play, заглушки Host game / Join game.

**Отладочная площадка:** шесть подписанных постаментов: Fireball, Ice, Lightning, Air, Earth, Test Wand. Подойдите к постаменту — палочка автоматически заменится даже в занятом слоте. Постамент остаётся на месте. Повторная замена происходит при новом подходе; простое стояние рядом не сбрасывает заряд. Три подвижные тренировочные мишени и постоянная стенка позволяют проверять урон, отталкивание и рикошеты. Стартовая палочка — Test Wand.

**Основной билд:** отдельное лобби с безопасной Test Wand и обозначенными порталами. Здесь нет постаментов, боевых палочек на земле и тренировочных мишеней. Порталы пока недоступны: игровые локации ещё не реализованы. Основной билд сейчас является прототипом лобби, а не полным прохождением.

В обеих сценах можно выбросить палочку нажатием на слот и подобрать её в пустой слот. Обычный предмет на земле не заменяет занятую палочку. После выбрасывания действует задержка повторного подбора 0,8 с. Правило автоматической замены на постаменте существует только там, где сцена содержит постаменты.

## Палочки

| Палочка | Normal | Special |
|---|---|---|
| Fireball | Огненный снаряд | Сфера огня вокруг персонажа |
| Ice | Веер маленьких сосулек | Летящая вперёд волна холода, поражает каждую мишень один раз |
| Lightning | Мгновенная линия молнии | Удар с неба в точку впереди; прицел удаляется при зарядке; применяется при отпускании даже с частичным зарядом и игнорирует стену на пути |
| Air | Вихрь наносит урон при попадании и расталкивает близкие цели | Сфера сильно отталкивает цели от персонажа; урон не добавлен, поскольку он не задан |
| Earth | Катящийся камень рикошетит от стен и границ | Временная твёрдая стена перед персонажем, не имеет здоровья и не разрушается атаками |
| Test Wand | Искры без урона, слегка отталкивающие цель | Безопасная сфера без урона и отталкивания |

Special всех палочек, кроме Lightning, в текущем прототипе требует полного заряда. При попытке создать стену Earth на персонаже, мишени или другой стене стена не создаётся. Для простой геометрии стена ориентируется по одной из двух осей, поперёк основного направления прицеливания. Камень наносит урон каждой цели не более одного раза за применение.

## Управление и баланс

Игра портретная: на широком экране 9:16, на вертикальном телефоне — вся доступная высота и ширина. Камера следует по горизонтали; `cameraZoom: .72` даёт примерно на 39% больше пространства по каждой оси. Слева внизу — вертикальный ползунок Safe/Normal/Special снизу вверх, по центру — джойстик, справа — слот палочки и пустой слот руны. Ползунок переключается свайпом, нажатием или стрелками при фокусе; Home/End выбирают края.

Зарядка идёт от удержания джойстика или игрового поля, даже в центре джойстика, без движения. WASD/стрелки — движение и удержание для зарядки; противоположные клавиши останавливают движение, сохраняя зарядку. Все атаки срабатывают при отпускании. Safe не стреляет. Смена режима, выбрасывание, смена палочки на постаменте, отмена жеста и потеря фокуса отменяют заряд.

Временные числа собраны в `src/balance.js`. Минимум дальности Normal — 1% максимума, минимум урона — 0,01%; рост идёт по квадрату заряда. Fireball растёт от радиуса 0,6 до 12. Серия из 20 нажатий по 40 мс наносит менее 5% урона одного полного Fireball. Значения и кривая ещё требуют балансировки. Стена Earth существует 6 секунд — временное число из файла баланса.

Временное правило коллизий: стены блокируют персонажа, отталкиваемые цели, обычные снаряды, линию Lightning и волну Ice. Камень Earth рикошетит, удар Lightning с неба применяется напрямую за стеной. GDD ещё не определяет все взаимодействия атак со стенами; эти правила нужно проверить отдельно. Самоурон, мана, здоровье, friendly fire и руны пока не реализованы. Нет сетевой игры, игровых локаций, биомов и боссов.

## Структура и проверка

- `scripts/build.mjs`: изолированные статические сборки.
- `src/scene.js`: точка входа сцены, заменяемая сборкой.
- `src/scenes/debug.js` / `lobby.js`: отдельные сцены и их данные.
- `src/balance.js` / `wands.js`: параметры и определения всех палочек.
- `src/simulation.js`: общее состояние, заклинания, коллизии, предметы и постаменты.
- `src/main.js` / `renderer.js` / `style.css`: ввод, заменяемая графика и адаптивный UI.

31 тест проверяет состав двух билдов и зависимости модулей, сцены, постаменты, зарядку, слабые быстрые выстрелы, все реализованные заклинания, отталкивание, рикошеты, блокирование и исчезновение стен. Реальный сенсорный телефон ещё не проверен.
