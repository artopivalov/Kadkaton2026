# Визуальные концепты

Два альтернативных направления для существующей вертикальной 2D-игры. Концепты — художественные ориентиры, а не утверждённые механики или точные макеты интерфейса. Перспектива иллюстраций немного наклонена; при реализации сохранить текущую камеру и управление.

## 01 — Enchanted Ink / Чернильная сказка

Рисованные контуры, бумажная фактура, мшистые руины, пергамент и латунь. Силуэты персонажей простые; декор концентрируется по краям арен. Лес — мох и камень, пещера — холодные кристаллы, библиотека — дерево и старые книги.

| Цвет | Роль |
|---|---|
| `#182C28` | Глубокие тени, контуры |
| `#496B4A` | Листва и мох |
| `#B8C88D` | Светлые поверхности |
| `#E9DDBB` | Пергамент, интерфейс |
| `#C58A45` | Латунь, детали предметов |
| `#EF795E` | Опасность и вражеские атаки |

Изображение: [enchanted-ink.png](enchanted-ink.png).

## 02 — Prism Ruins / Призматические руины

Геометрические формы, ограниченные ступени теней, тёмные окружения и яркие заклинания. Лес — светящаяся растительность, пещера — гранёные кристаллы, библиотека — строгие арки и рунические круги. Свечение локальное; пол светлее непроходимых границ.

| Цвет | Роль |
|---|---|
| `#101525` | Фон и глубокие тени |
| `#28354A` | Стены и окружение |
| `#52647C` | Проходимый пол |
| `#59E1E8` | Акцент магии игрока |
| `#A78BFA` | Порталы и руны |
| `#FF786C` | Опасность и вражеские атаки |
| `#EEEAF7` | Текст и нейтральный интерфейс |

Изображение: [prism-ruins.png](prism-ruins.png).

Для быстрого прототипа рекомендовано второе направление: простые формы легче перенести в Canvas, а контраст помогает читать бой. Обе палитры базовые: разные стихии требуют собственных форм и дополнительных цветов. Редкость предметов не должна определяться одним цветом; добавить символ или различие рамки. Изображения содержат декоративные примеры HUD, а не спецификацию управления.
