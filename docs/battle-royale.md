# Королевская битва / Battle Royale

Дата: 8 октября 2026. Статус: режим реализован в прототипе, включая сетевые снимки и одиночный тест.

## Подтверждённые правила

- Отдельный боковой портал **Battle Royale** в лобби. Целевой доступ — мультиплеер; временно доступен в одиночке для тестов.
- В мультиплеере участвуют все игроки текущего лобби. Старт по обычному правилу: все должны одновременно стоять в этом портале. Отдельного меньшего лимита режима нет.
- Круглая симметричная арена с равноценными стартовыми местами. Радиус увеличить относительно первого концепта; укрытия сделать чуть уже и разместить чаще.
- Каждый игрок при входе получает случайную **Legendary** палочку и случайную **Legendary** руну. Предметы из лобби не определяют стартовый набор. Симметрия обеспечивает равенство позиций; случайные наборы могут различаться по силе.
- HP каждого игрока ×10. Отталкивание **и притяжение** ×3 относительно обычного режима.
- Урон по другим игрокам сохраняет текущий множитель **50%**.
- Лава окружает арену и за **60 секунд** заполняет её до центра. Урон — **10% максимального HP в секунду**, после увеличения HP ×10. При базовых 100 HP это 1000 HP и 100 урона/с.
- В мультиплеере побеждает последний живой игрок; одновременная смерть последних игроков означает **ничью**.
- После смерти игрок **наблюдает** за матчем, без возрождения.
- В одиночном тесте есть **два неподвижных бота**. Они не ходят и не атакуют. Соло продолжается до смерти человека: гибель ботов не даёт автоматическую победу.
- У каждого игрока камера повёрнута вместе с его стартовым направлением и смотрит **к центру арены**. Сохраняется вид строго сверху; меняется поворот изображения в плоскости, а не наклон камеры. Поворот фиксируется при старте и не меняется при перемещении игрока.

## Предлагаемые уточнения для реализации

Эти решения не утверждены пользователем.

| Параметр | Предложение |
|---|---|
| Начальное здоровье | Полностью заполненное увеличенное HP у каждого участника |
| Скорость лавы | Линейное уменьшение безопасного радиуса: `r(t) = R × max(0, 1 − t / 60)` |
| Начало таймера | Одновременно с разрешением движения и атак после общего старта |
| После 60 с | Вся арена опасна, включая центр; урон продолжается до смерти/победы |
| Расчёт урона | Непрерывно по времени нахождения в лаве, без зависимости от FPS; 0.25 с = 2.5% максимального HP |
| Геометрия попадания в лаву | По центру персонажа; точную границу и визуальную обратную связь согласовать |
| Точки старта | Равномерно по окружности радиуса 0.78R; случайное распределение игроков по равноценным местам |
| Укрытия | Два кольца на 0.42R и 0.66R, по 3N коротких сегментов в каждом; длина 100, толщина 24, против прежних ≈182 × 45. Внутреннее кольцо сдвинуто на половину шага; центр открыт |
| Радиус | Первый тест R = 900 вместо 540 (увеличение ≈67%); точное значение подбирается игровым тестом |
| Множители силы | ×3 применять после текущих модификаторов к отталкиванию и притяжению; с руной Сила ×5 итоговый множитель ×15. Точные исключения для контроля уточнить |
| Укрытия и лава | Лава проходит под стенами; стены не создают безопасных островков |
| Сеть | Хост задаёт время старта, рассчитывает лаву, смерти и результат; клиенты показывают одно состояние |
| Наблюдение | По умолчанию камера следующего живого участника; переключение между живыми игроками. При смерти человека в соло — результат, а не ожидание ботов |
| Ввод и HUD | Вектор движения переводится из экранных координат в мировые через обратный поворот камеры; прицеливание аналогично. HUD и подписи над игроками остаются читаемыми |
| Боты соло | Человек и два бота занимают три равных сектора; те же HP ×10 и случайные Legendary предметы. Боты получают урон, могут быть сдвинуты заклинаниями, умирают в лаве, но не выполняют действия |
| Сброс режима | ×10 HP и ×3 отбрасывания не накапливаются при повторном входе и не переносятся в другие сцены |

Линейный радиус даёт радиусы R / 0.75R / 0.5R / 0.25R / 0 на 0 / 15 / 30 / 45 / 60 секунде. Площадь безопасной зоны уменьшается нелинейно. Минутный таймер означает время заполнения арены, а не обязательный конец матча. При полной жизни и без лечения урон лавы убивает за 10 секунд суммарного нахождения в лаве.

## Концепт сцены

[Открыть SVG](art-direction/battle-royale-concept.svg) · [PNG-превью](art-direction/battle-royale-concept.png). Это точная схема сверху в палитре проекта, а не готовая сцена или утверждённый HUD. Четыре участника показаны как пример; реальный состав равен составу лобби. Текущая сетевая инфраструктура допускает комнаты до восьми игроков; режим наследует её ограничения.

- Круглый каменный пол с тёплым контуром, яркая коралловая лава с редкими светлыми прожилками.
- Четыре стартовые точки и два кольца по 12 узких укрытий связаны поворотом на 90°. Каждый игрок получает те же расстояния до центра, лавы и ближайшего укрытия. Схема показывает предложенный радиус 900 и направления камер к центру.
- Стены не образуют замкнутых карманов; можно обходить с обеих сторон. Центр открыт для последней схватки.
- Справа показаны состояния заполнения на 0, 30 и 60 секундах; пунктир на основной арене — планировочная отметка фронта на 30 секунде, не второй фронт лавы.
- Внизу — схема лобби с отдельным боковым порталом, без изменения трёх обычных порталов.
- При другом числе участников требуется N одинаковых секторов с поворотной симметрией, а не занятые частично четыре места. Размер стен и проходы проверяются для выбранного N.

## Параметры для последующего игрового теста

Точные размеры арены и укрытий, линейный профиль лавы, наличие дополнительного лута и баланс лечения остаются предметом игрового теста. Для первого прототипа применены рабочие решения из раздела реализации ниже; они не препятствуют запуску режима.

## Критерии проверки реализации

- Боковой портал доступен в одиночке только пока включено тестовое исключение.
- Стартовые места и укрытия равноценны для каждого поддерживаемого числа участников.
- HP и отбрасывание меняются только внутри режима, включая повторные матчи.
- На 30 с безопасный радиус равен 0.5R, на 60 с безопасных точек нет, если принят предложенный профиль.
- Урон лавы соответствует времени контакта и увеличенному максимальному HP; PvP-коэффициент 50% не уменьшает урон лавы.
- Матч начинается только при входе всех участников лобби; каждый получает Legendary палочку и руну.
- Отталкивание и притяжение усиливаются ×3.
- Одновременное выбывание последних фиксируется как ничья; умершие игроки наблюдают.
- Два соло-бота не ходят и не атакуют, но участвуют в уроне/физике. Соло заканчивается при смерти человека независимо от ботов.
- Центр расположен впереди каждой стартовой камеры; движение и прицеливание соответствуют экранным направлениям после поворота.
- Укрытия сохраняют поворотную симметрию для фактического числа участников, включая три сектора соло.
- Последний выживший получает победу; одиночный игрок не выигрывает при старте.
- Хост и клиенты согласны по началу, фронту лавы, выбыванию и исходу; спорные случаи покрываются после утверждения правил.

## Реализация от 8 октября 2026

Режим находится в `src/battle-royale.js`, настройки — `BATTLE_ROYALE_BALANCE` в `src/balance.js`. Боковой портал доступен в основном лобби; вся группа входит одновременно. Соло получает два неподвижных бота. Выдаются случайные Legendary палочка и руна, HP = 1000 при базовых 100, отталкивание/притяжение ×3 с сохранением PvP 50%.

Первый баланс: радиус 900, два кольца укрытий на 0.42R и 0.66R, по три на сектор в каждом кольце. Длина не больше 100, толщина 24; для больших групп длина автоматически уменьшается, чтобы кольцо сохраняло проходы. Укрытия повёрнуты тангенциально, столкновения и отражения используют ту же геометрию.

Приняты рабочие решения из предложений: линейное сужение за 60 секунд, проверка лавы по центру персонажа, полный запас здоровья при старте. Лава продолжает наносить урон после заполнения центра и не использует множитель PvP. После смерти — наблюдение с кнопкой **Next player**. После результата — **Return to lobby** для общего возврата; выданное снаряжение заменяется обычным стартовым. Отключение участника считается выбыванием, поздние подключения в активный матч отклоняются. Выход хоста закрывает сессию по существующему сетевому правилу.

Камера фиксирует поворот по стартовому сектору. Движение и направление заклинаний преобразуются из экранных координат в мировые; полосы ресурсов и имена остаются горизонтальными. Наблюдатель получает камеру выбранного живого игрока.

Для PvP в этом режиме расширены цели Nature, Gravity, Crystal и Storm/Void: контроль, поля, ловушки, цепи и наведение действуют на живых соперников. Blood лечит владельца при попадании по сопернику в пределах увеличенного максимального HP. Лечащая руна сохраняет обычное действие с множителем 50%; отдельный лут не добавлен. Эти рабочие решения можно изменить по игровому тесту.

Проверка: **173 теста прошли**, собраны debug/game/generation. В браузере проверены боковой портал, вход в соло, Legendary-снаряжение, два бота и сужение лавы; ошибок консоли нет. [Снимок реализованной сцены](art-direction/battle-royale-preview.png).

Автоматические проверки покрывают старт всей группы, равные позиции для 2–8 игроков, легендарную выдачу, ботов, лаву, одновременные смерти, силы, геометрию укрытий, PvP-поля, камеру, очистку режима и хост/клиент через тестовый сетевой транспорт. Реальный сетевой сеанс на нескольких устройствах и сенсорный телефон отдельно не проверены.
